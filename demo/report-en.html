How these measurements were made

  • A probe wired to the router tests the connection at regular intervals, around the clock.
  • Each check tests, in order: the router (gateway), Internet servers by IP address, name resolution (router DNS and public DNS), then access to a web page.
  • The first step that fails shows where the problem is. An outage is only counted after several failed checks in a row, to avoid false alarms.
  • Times are local. Raw data stays with the user and can be exported.
